cer4all Webflasher

USB nach BLE für Certabo, Spectrum und Sentio.

Testversion 0.1.5-dev · Automatische 180°-Ausrichtung für Certabo/Spectrum · BLE-Optimierung erhalten · Hardwaretest steht aus.

Chrome oder Edge am Computer verwenden. Zum Flashen das Brett abziehen und das ESP32-S3-Modul mit einem USB-Datenkabel anschließen. Die Installation ersetzt die Firmware auf diesem Modul.

ESP32-S3 Mini · 4 MB

Für Waveshare ESP32-S3-Zero / S3FH4R2.

Falls kein Download-Port erscheint: BOOT gedrückt halten, RESET kurz drücken, dann BOOT loslassen. Nach dem Flashen RESET drücken oder die Stromversorgung kurz trennen. Die USB-Buchse wird danach für das Brett verwendet.

Web Serial fehlt. Bitte Chrome oder Edge am Computer verwenden.

ESP32-S3 WROOM · 16 MB

Für ESP32-S3-WROOM-1-N16R8 (16 MB Flash, 8 MB RAM). Über USB-UART flashen und versorgen; der native USB-OTG-Anschluss ist für das Brett.

Web Serial fehlt. Bitte Chrome oder Edge am Computer verwenden.

Automatische Ausrichtung

Bei Certabo und Spectrum nach dem Einschalten zuerst die normale Startstellung mit Weiß auf den Reihen 1 und 2 aufbauen. Wer Schwarz unten spielen möchte, lässt das Brett stehen und baut die vollständige Startstellung um 180° gedreht auf. Die vier mittleren Felder blinken zweimal zur Bestätigung. Zusätzliche Damen sind dafür nicht nötig. Die normale Startstellung schaltet wieder zurück.

Wer das gesamte Brett dreht, muss nichts ändern. Sentio unterstützt diese Automatik nicht.

Nach dem Flashen testen

  1. Das Brett über ein geeignetes, extern versorgtes OTG-Y-Kabel verbinden.
  2. In der Schachsoftware das BLE-Gerät Certabo auswählen. Diesen Namen nutzt cer4all für beide Bretttypen.
  3. Das Einlernen der Figuren in der Schachsoftware durchführen.
  4. Logs wie beim Gateway in der Android-App eChessboards unter Gateway Log einschalten und herunterladen. Dazu die Schach-App vorher vom Modul trennen.

Keine festen Figuren-IDs.
